# Recruitment Telegram Autopilot

A Railway-friendly infinite-loop autopilot for sending recruitment telegrams to NationStates nations.

## Features

- **Looped autopilot**: Continuously reads `targets.txt` and sends telegrams
- **Persistent state**: Tracks sent nations in-memory during runtime
- **Resilient**: HTTPAdapter with exponential backoff on 429/5xx errors (3 retries)
- **Environment-driven**: All secrets via environment variables (no hardcoding)
- **Railway-ready**: Structured for Railway deployment with proper signal handling

## Setup

### 1. Install dependencies

```powershell
pip install -r requirements.txt
```

Or with a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 2. Configure environment variables

Set these in your shell or Railway dashboard:

- `NS_CLIENT_KEY` - Your NationStates API client key (required)
- `NS_TGID` - Telegram ID in your nation (required)
- `NS_SECRET_KEY` - Your NationStates API secret (required)
- `NS_USER_AGENT` - User-Agent header (default: "WalbardRecruitBot")
- `NS_DELAY` - Seconds between telegram sends (default: 180)
- `NS_POLL_SLEEP` - Seconds between target list polls (default: 60)

### 3. Create `targets.txt`

List target nations one per line. Comments start with `#`:

```
# Target nations for recruitment
nation1
nation2
nation3
```

### 4. Run the autopilot

```powershell
python recruitment.py
```

The script will:
- Load targets from `targets.txt` every 60 seconds
- Track which nations have already received telegrams
- Send telegrams with 180-second delays between each
- Sleep 60 seconds if no new targets found
- Press `Ctrl+C` to stop

Tests include:

## Deployment to Railway

1. **Push to git**:
   ```powershell
   git add .
   git commit -m "Recruitment autopilot"
   git push
   ```

2. **Create Railway project** at https://railway.app/

3. **Set environment variables** in Railway dashboard:
   - `NS_CLIENT_KEY`
   - `NS_TGID`
   - `NS_SECRET_KEY`

4. **Railway will automatically run**: `python recruitment.py`

## How it works

1. **Session setup** (`make_session`): Creates a requests.Session with HTTPAdapter for retry/backoff
2. **Send telegram** (`send_tg`): Posts to NationStates API, validates env vars, handles errors
3. **Load targets** (`load_targets`): Reads `targets.txt`, filters comments and blank lines
4. **Main loop** (`main_loop`): Infinite loop polling targets, tracking sent nations, sending TGs with delays

## Persistent State (Optional)

Currently, sent nations are tracked in-memory and reset on restart. For persistent tracking across restarts, modify `main_loop()` to:
- Load sent nations from `sent_nations.json` on startup
- Save sent nations to `sent_nations.json` after each successful send
- Survive Railway container restarts
