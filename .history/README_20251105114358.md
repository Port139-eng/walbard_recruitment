# Recruitment telegram sender

Improved `recruitment.py` for sending recruitment telegrams to NationStates.

Features:
- CLI: pass `--targets` or `--targets-file`
- Configurable delay and retry behavior
- Uses `requests.Session` with retry/backoff
- Reads API keys from environment variables if set
- `--dry-run` mode for safe testing

Quick start:

1. (Optional) Create a virtual environment and install requirements:

```powershell
python -m venv .venv; .\.venv\Scripts\Activate.ps1; pip install -r requirements.txt
```

2. Run with inline targets:

```powershell
python recruitment.py --targets nation1 nation2 --delay 180
```

3. Or with a file `targets.txt` (one nation per line):

```powershell
python recruitment.py --targets-file targets.txt
```

Set the following environment variables for production secrets:
- `NS_CLIENT_KEY`
- `NS_TGID`
- `NS_SECRET_KEY`
